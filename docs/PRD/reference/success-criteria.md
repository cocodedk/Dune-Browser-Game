# Success Criteria

## PoC Success

The PoC is successful if:

- Player can play 5–10 minutes without crashes or confusion
- AI produces believable behavior (not random, not game-breaking)
- The loop feels meaningful — decisions have visible effects
- Player wants to keep playing

## Full Game Success

Core loop is complete when the player can:

1. Click a village
2. Travel there
3. Talk to the leader
4. Influence loyalty
5. See time pass
6. Watch spice accumulate
7. Save in browser storage and resume the same run later

Additional criteria:

- AI factions behave dynamically (Harkonnen pressure, Fremen unity, smuggler opportunism)
- Replayable due to emergent faction behavior
- Save/resume restores a playable world state instead of starting over
