- Map
- Time system
- Travel

## Phase 2 — Interaction (2–4 weeks)

- Villages
- Dialogue
- UI

## Phase 3 — Systems (4–8 weeks)

- Economy
- AI
- Events

## Phase 4 — Polish (ongoing)

- Balancing
- Pacing
- UX
