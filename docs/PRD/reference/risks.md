# Risks

## Known Risks

1. **Overusing React** — kills performance
2. **No clear state model** — impossible to debug
3. **Too much rendering logic in Phaser** — UI becomes painful to maintain
4. **Content explosion** — dialogue and balancing take longer than code

## Mitigation

Keep the engine in pure TypeScript. Define clear layer boundaries from day one.
